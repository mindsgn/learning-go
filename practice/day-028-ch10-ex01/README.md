
# Day 028 - Chapter 10 Exercise 1

**Chapter:** Modules, Packages, and Imports

## Original Prompt

1. Create a module in your own public repository. This module has a single func‐ tion named Add with two int parameters and one int return value. This function adds the two parameters together and returns them. Make this version v1.0.0.

## Acceptance

For offline practice, use a local `VERSION` file instead of a public repo tag. Implement `Add(a, b int) int` in package `adder` and set `VERSION` to `v1.0.0`.

Run `go test` inside this folder when you want feedback.
